<p style="font-size: 21px;">
    2. Análise de Times e Ligas de Futebol
</p>
<p style="font-size: 18px;">
E se uma pessoa pretende saber um pouco mais sobre times de ligas de futebol como estatísticas ou histórico de confrontos? Não é difícil de conseguir essas informações, mas para isso a pessoa deve acessar vários sites diferentes para consegui-las.<br>
Este projeto visa concentrar essas informações em um só lugar com uma interface amigável, rica em detalhes e atualizada.<br><br>
